# Shotgun Surgery term used incorrectly

## Problem

CDD uses "Shotgun surgery" term whel talking about changes spread across various files in various directories in the database, in a feature that should be cohesive. This is not a precise term. "Shotgun surgery" apparently refers to something else: https://en.wikipedia.org/wiki/Shotgun_surgery

## Impact

The incorrect use of this term when talking about a common problem this methodology solves makes CDD itself less credible

## Desired outcome

A correct term is used
