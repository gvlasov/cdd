A [Subject](/concepts/subjects/Subject.md) that has [[beliefs]] about how concepts can be represented and the outcomes of [processes](/concepts/processes/Process.md) that he can run.

Every systems are built for users. Every system is assumed to have users. A good system knows about its users, specifies and models their intent, [Goal](/concepts/goals/Goal.md), assumptions, preferences.

### Examples
- A user of Google search engine - this is an example where the user is a [Stakeholder](/concepts/stakeholders/Stakeholder.md)
- A program that calls `grep` (the belief is that it will filter the provided text) can be considered a users, but in actuality the developer that wrote that program
