A [[Subject]] that has [[beliefs]] about how concepts can be represented and the outcomes of [[Process|processes]] that he can run.

Every systems are built for users. Every system is assumed to have users. A good system knows about its users, specifies and models their intent, [[goals|Goal]], assumptions, preferences.

### Examples
- A user of Google search engine - this is an example where the user is a [[stakeholder|Stakeholder]]
- A program that calls `grep` (the belief is that it will filter the provided text) can be considered a users, but in actuality the developer that wrote that program
